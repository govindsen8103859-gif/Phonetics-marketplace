PHONETICS WEBSITE FILES

Files:
- index.html: main responsive website page
- privacy.html: draft privacy page for the prototype
- manifest.webmanifest: basic install metadata for a future PWA

IMPORTANT LIMITATIONS
This is a front-end prototype. GitHub Pages only hosts static files. The seller/buyer forms do not submit to a secure server, photos are not uploaded, listings are not saved, and there is no secure admin login or approval system yet. Do not collect real seller phone numbers or private asking prices until a backend and authentication are configured and tested.

UPLOAD
Upload the contents of this folder to the ROOT of the GitHub repository. Keep the main page filename exactly index.html. After uploading, wait for GitHub Pages to redeploy and open the Pages URL.

This package is a website, not an Android APK. Creating a working marketplace with private seller details requires a backend/database and admin authentication; simply uploading static files cannot safely provide those functions.
